# AI Agent 将重新定义"工作"

## 核心立场

> 未来 3 年内，"一个人 + AI Agent"的组合将能完成今天 5 人团队的日常工作量。工作的定义将从"执行任务"变为"管理 Agent"。

## 置信度

85% — 基于当前 AI 能力的指数增长趋势和个人实践体验。

## 论据

1. 代码领域已初步验证：Cursor/Claude Code 让一个人能做过去一个小团队的事
2. 内容领域正在验证：AI 生成 + 人工审核的效率远超纯人工
3. Agent 的能力在快速提升：从单一任务到多步骤工作流

## 反面论据

- AI 的"幻觉"问题仍未完全解决
- 复杂决策仍需人类判断
- 监管和伦理问题可能拖慢进程
