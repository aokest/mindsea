# MindSea AI 协作工作流

> 版本: 2.0 | 本文档定义了人与 AI 在知识管理中的协作模式。

---

## 一、三层架构

```
┌─────────────────────────────────────────────┐
│              触达层 (Touch Layer)             │
│         AI Agent — 日常交互入口               │
│     快速响应 / 知识检索 / 内容生成 / 导航      │
├─────────────────────────────────────────────┤
│              深度层 (Deep Layer)              │
│       Deep Agent — 深度分析引擎               │
│   知识图谱构建 / 跨域关联 / 趋势分析 / 归档     │
├─────────────────────────────────────────────┤
│              存储层 (Storage Layer)           │
│         Obsidian — 知识持久化                  │
│     Markdown 文件 / 双向链接 / 本地搜索         │
└─────────────────────────────────────────────┘
```

---

## 二、核心工作流

### 2.1 知识输入流

```
[原始素材] → [AI Agent 理解] → [选择域和实体类型] → [填充模板] → [建立关联] → [存入 Obsidian]
```

### 2.2 知识孵化流

```
[学习域概念] → [创意域思想] → [反复打磨] → [成熟观点] → [工作域执行]
```

阶段流转：

| 阶段 | 状态 | 域 | 行为 |
|---|---|---|---|
| 种子期 | `seed` | creative | 一个模糊的想法，快速记录 |
| 生长期 | `growing` | creative | 添加论据、关联、反驳 |
| 成熟期 | `mature` | creative | 观点清晰，逻辑自洽 |
| 执行期 | `active` | business | 转化为项目或行动计划 |

### 2.3 知识沉淀流

```
[所有域的事件] → [日报] → [实体沉淀] → [概念沉淀] → [长期知识积累]
```

### 2.4 知识审计流（每周）

| 检查项 | 标准 | 处理方式 |
|---|---|---|
| 孤儿笔记 | 无任何链接 | 标记为待关联或待归档 |
| 过期内容 | `review_by` 已过期 | 通知用户复审 |
| 命名违规 | 不符合命名规范 | 自动重命名或提醒 |
| 标签碎片 | 低频标签（< 2次） | 建议合并或删除 |
| Frontmatter 缺失 | 必填字段为空 | 提醒补充 |
| 隐私泄露 | 🔴 内容出现在公开域 | 立即告警 |

## 三、操作协议

### 创建操作
```
用户指令 → AI Agent 解析意图 → 加载模板 → 填充 Frontmatter → 生成文件名 → 写入 Obsidian → 建立关联（双向）→ 返回确认
```

### 查询操作
```
用户查询 → AI Agent 理解语义 → 检索相关笔记 → 组织结果 → 呈现给用户
```

### 归档操作
```
过期/完成 → AI Agent 标记归档 → 更新 status → 保留链接完整性 → 记录归档原因
```

## 四、通信协议

### 触达层 → 深度层

| 事件 | 优先级 | 说明 |
|---|---|---|
| 新实体创建 | 低 | 用于图谱更新 |
| 关联变更 | 中 | 可能影响图谱结构 |
| 大批量更新 | 高 | 需要重新分析图谱 |
| 隐私等级变更 | 高 | 需要安全审查 |

### 深度层 → 触达层

| 推送物 | 频率 | 说明 |
|---|---|---|
| 图谱健康度 | 每周 | 孤儿笔记数、过期内容数 |
| 关联建议 | 每日 | 新发现的潜在关联 |
| 归档建议 | 每周 | 建议归档的内容清单 |
| 趋势洞察 | 每月 | 知识积累趋势分析 |

---

## 五、异常处理

- **同名冲突**: 自动添加时间戳后缀，提醒用户
- **关联冲突**: 保留最新关联，归档旧关联
- **回滚**: 每次写操作前自动备份，保留最近 10 个版本
- **隐私安全**: 🔴 内容仅本地存储，永不上传
